# XBench

XBench studies how mobile manipulators act in time as their surroundings change. The catalogue lists 30 tasks. Each task has a Harbor-style profile with instructions, environment, tests, status and media availability.

Open `index.html` directly to browse offline. All pages use relative links. The publishing workflow deploys the static files from `main` to GitHub Pages.

See [贡献指南](CONTRIBUTING.md) for editing and media instructions.
